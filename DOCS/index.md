# Cog

Cog (Cloud On Go) is a file storage and plugin platform written in Go. It provides WebDAV, SFTP, and web-based file access with built-in apps for calendars, contacts, notes, tasks, RSS feeds, photo galleries, and bookmarks. Cog maintains API compatibility with NextCloud clients and ecosystem apps.
